INTERPRETATION GUIDE
================================================================================
P-values: Exact permutation-based p-values (more reliable than z-scores)
  - Calculated as (# null values >= observed + 1) / (# permutations + 1)

FDR (False Discovery Rate) correction:
  - Controls expected proportion of false positives among rejected hypotheses
  - Benjamini-Hochberg: Standard FDR control
  - Benjamini-Yekutieli: Conservative FDR for dependent tests
  - Bonferroni: Most conservative, controls family-wise error rate

Recommendations:
  - Use FDR q<0.05 for exploratory analysis
  - Use FDR q<0.01 for confirmatory analysis
  - Use Bonferroni for strict control when few tests
